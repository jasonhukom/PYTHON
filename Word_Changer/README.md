# Word_Changer

> A planned **find-and-replace tool for paragraphs**: tell it which words to change and what to change them into.

**Status:** 🚧 Unfinished. It asks the questions but doesn't replace anything yet.

## 💡 The idea

1. Ask how many words you want to change.
2. Ask for each word, then what it should become.
3. Ask whether to remove capitalisation.
4. Run the replacements on a paragraph.

## 🚧 Where it stands

Step 4 isn't connected. The `changer()` function is a sketch and is never called, so no paragraph is read or changed. A few lines also have mistakes (for example `wordcghe` is a typo).

## ▶️ Run it

```bash
python3 word_changer.py
```
