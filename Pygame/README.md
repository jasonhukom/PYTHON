# Pygame · Mushrams: Power Up!

> An early prototype of a pygame game called **Mushrams: Power Up!**

**Status:** 🚧 Prototype

## 🎮 What works so far

- A title screen showing **MUSHRAMS** and **Power Up!** for 3 seconds.
- A sky and ground background.
- An enemy sprite you move with the **← / →** arrow keys. It flips to face the way it walks and stays inside the window.

## ▶️ Run it

```bash
pip install pygame
python game.py
```

Run it from this folder: the game loads its images and fonts from `./images/`.

## 📁 What's here

| Path | Contents |
| --- | --- |
| `game.py` | The game |
| `images/` | `sky.png`, `ground.png`, `enemy.png`, `floor.png`, `money_particles.png` and the fonts |
| `images/font/`, `font/` | The same set of unpacked fonts in two places |
| `images/*.zip` | The original font downloads |
